# Ütem – Szokáskövető

Egyszerű, gyors szokáskövető app – telefonra telepíthető, internetkapcsolat nélkül is működik.

🔗 **Live app:** [greativo13.github.io/szokaskovet-](https://greativo13.github.io/szokaskovet-)

---

## Ingyenes funkciók

- Max 5 napi szokás nyomon követése
- Streak számlálás és legjobb sorozat
- Heti grafikon
- Drag & drop átrendezés
- Offline működés (PWA)

## Pro verzió

A Pro verzió kulcs alapú aktiválással érhető el:

- Korlátlan szokás
- Heti és havi frekvencia
- Éves hőtérkép
- Célvarázsló – szokáscsomag összeállítás cél alapján
- Kihívások
- Export CSV / Backup
- Sötét / közép / világos téma

**Pro kulcs vásárlása:** greativo13@gmail.com

---

## Telepítés (főképernyőre)

1. Nyisd meg az appot **Safari**-ban (iOS) vagy **Chrome**-ban (Android)
2. Koppints a Megosztás ikonra → **Főképernyőre**
3. Kész – úgy működik mint egy rendes app
